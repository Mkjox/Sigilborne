# Sigilborne

A digital collectible card game app featuring tactical deck building, dynamic board combat, and campaign progression.

## Project Overview

- Fast-paced card duels with heroes, spells, and units.
- Deep deck customization and strategic choices.
- Campaign mode, collection management, and battle screens.
- Built with React Native and TypeScript.

## Key Areas

- `App.tsx` - app entry point.
- `src/screens` - user-facing game and menu screens.
- `src/components` - reusable UI and gameplay components.
- `src/engine` - core game rules, ability system, and AI.
- `src/store` - application state and game data management.
- `assets` - art, sound effects, and media used in the game.

## Gameplay Style

- Assemble a custom deck with units, spells, and support cards.
- Each match combines hand management, board positioning, and timing.
- Designed for a card battler experience with clear, responsive controls.
